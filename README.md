# REAL_ME_CHECK  REAL ME CHECK — мектепке арналған веб-жүйе

Қазақ тіліндегі Flask + SQLite веб-қосымшасы. Оқушы/мұғалім аккаунттары, сыныпқа қосылу, 10 сұрақтық тест, нәтижелер тарихы, 5 күндік тапсырмалар, сыныптың жиынтық талдауы және аккаунтты жою бар.

## Іске қосу

Python 3.10+ орнатыңыз. Терминалда:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Браузерде `http://127.0.0.1:5000` ашыңыз. Алдымен мұғалім аккаунтын тіркеп, сынып құрыңыз. Сыныптың 8 таңбалы кодын оқушыларға беріңіз. Оқушылар жеке тіркеліп, кодпен қосылады.

## Серверге орналастыру

Өндірістік ортада ұзақ әрі кездейсоқ `SECRET_KEY` орнатыңыз, HTTPS прокси және `HTTPS_ONLY=1` пайдаланыңыз. Мысалы:

```bash
export SECRET_KEY="$(python -c 'import secrets; print(secrets.token_hex(32))')"
export HTTPS_ONLY=1
waitress-serve --listen=127.0.0.1:5000 app:app
```

**Маңызды:** Бірінші рет іске қоспас бұрын `python -c "from app import init_db; init_db()"` орындаңыз. Reverse proxy (мысалы, Nginx), TLS сертификаты, резервтік көшіру, бақылау және нақты мектептің деректерді өңдеу саясаты қажет.

## Қауіпсіздік пен шектеулер

- Құпиясөздер хэштеледі, сессия cookie-лері HttpOnly/SameSite, POST формалары CSRF токенімен қорғалған.
- Мұғалім жеке тест жауаптарын көрмейді; сынып талдауы кемінде 5 тест тапсырған оқушы болғанда ғана көрінеді.
- Логин арқылы нақты тұлғаны жанама тану мүмкін; 5 адам шегі толық анонимдікке кепіл емес.
- Мұғалім рөлі өз бетінше тіркеле алады — нақты мектепте мұғалімді әкімші бекітетін механизм қосу қажет.
- Қате парольді көп рет енгізуді шектеу, email/2FA, парольді қалпына келтіру, әкімшілік аудит, деректерді сақтау мерзімі, құқықтық келісім және тәуелсіз қауіпсіздік тексерісі өндірістік пайдалануға дейін енгізілуі тиіс.
- Тест ғылыми тұрғыдан валидтелмеген, нәтижелер диагноз немесе тұлғалық баға емес.
- `realme.sqlite3` — дерекқор файлы. Оны жарияламаңыз немесе ZIP-ке қоспаңыз.

## Құрылым

`app.py` — сервер және дерекқор логикасы; `templates/` — беттер; `static/style.css` — дизайн; `requirements.txt` — тәуелділіктер.
